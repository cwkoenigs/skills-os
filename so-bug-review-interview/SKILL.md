# Bug-review interview

Follow [cadence-core.md](cadence-core.md) for the interview cadence.

Establish the observed and expected behavior, reproduction steps, affected
environment, and any known regression window. Inspect relevant code and logs
before asking for information the repository can provide.

Produce a bug brief with supporting evidence, likely causes clearly labeled as
hypotheses, and a way to verify the fix. Record when reproduction is incomplete.
