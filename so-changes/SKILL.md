# Changes

Determine the requested comparison and inspect its diff. When no comparison is
specified, summarize the current staged and unstaged changes and identify
relevant untracked files.

Explain what behavior changed and why, grouping related files by purpose.
Include available validation evidence and unresolved limitations. Distinguish
checks actually run from checks merely recommended.
