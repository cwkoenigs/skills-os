# Feature-build interview

Follow [cadence-core.md](cadence-core.md) for the interview cadence.

Establish the desired outcome, affected users, and relevant existing behavior.
Resolve questions about user flows, data, integrations, and constraints only when
they affect the implementation.

Produce a brief covering scope, acceptance criteria, likely code touchpoints,
and meaningful validation. Label unresolved choices and assumptions explicitly.
