# Best-practice audit

Identify the requested audit scope and the project's existing conventions.
Inspect relevant code, configuration, and checks. Use maintained material in
`references/` when it applies to the project's stack.

Report concrete findings with file locations, impact, and practical next steps.
Distinguish defects from optional improvements and state any gaps in verification.
Keep fixes within the user's requested scope.
