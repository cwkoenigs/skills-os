# Initialize project context

Inspect existing documentation, manifests, configuration, and contributor
instructions. Preserve established conventions when adding project guidance.

Use [platform.example.md](platform.example.md) as a starting point for the
requested platform document. Fill it with verified project facts and mark unknown
values clearly. Consult relevant material in `references/` if present.

with any setup that remains unresolved.
