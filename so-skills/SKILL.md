# Maintain skills

Follow [cadence-core.md](cadence-core.md) when the intended workflow needs
clarification. Define the requests the skill should handle and the expected
outcome before choosing its supporting resources.

Keep the skill folder and frontmatter name consistent. Write a concise
description that explains when the skill applies, and put workflow guidance in
the Markdown body. Link supporting references where they are needed.

Check frontmatter and local links, and run any new scripts. When editing this
collection's shared resources, run its `build.sh` to refresh the bundled copies.
